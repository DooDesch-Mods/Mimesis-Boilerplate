# Changelog

## [1.2.0] - 2026-10-28

### Changed

- Generate a new mod with a cross-platform Python command instead of renaming in place and deleting Git history.
- Generated projects build independently from the installed MelonLoader references, without a private Workspace or token.
- Keep preferences nullable-aware and initialization explicit. Use one version for the assembly and MelonInfo.
- Add repeatable generator checks, Windows/Linux build checks and a source kit for developers.
